# 📖 htmlbook-drive

**구글 드라이브의 HTML · Markdown 파일을 파인더처럼 탐색하고, 웹페이지 형태로 보고, 그 자리에서 고치는 뷰어·편집기입니다.**

서버 없이 브라우저에서만 동작하는 정적 사이트입니다. 맥·윈도우·아이폰·안드로이드 어디서든
브라우저로 접속해 같은 화면을 씁니다. 폰에서는 "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.

- 🗂 **파일 탐색기** — 내 드라이브를 폴더 트리로 탐색. 검색, 최근 문서, 별표, 폴더 고정(📌) 지원.
- 📄 **이중 모드 렌더링** — 자체 CSS/JS 가 있는 HTML 은 샌드박스에서 **원본 그대로**,
  스타일이 없는 HTML·Markdown 은 리더가 **테마를 입혀** 읽기 좋게. (htmlbook.io 방식)
- ✏️ **본문 편집** — 렌더된 화면에서 텍스트를 **탭(클릭)해서 바로 수정**. 수정분은 소스에
  정밀 텍스트 패치로 반영되어 스크립트·스타일이 보존됩니다.
- 🧑‍💻 **소스 편집** — CodeMirror 코드 편집기 + 실시간 미리보기 분할 화면.
- 💾 **자동 저장** — 입력이 멈추고 2.5초 뒤 드라이브에 저장. `Cmd/Ctrl+S` 즉시 저장.
  다른 곳에서 파일이 바뀌었으면 덮어쓰기 전에 알려줍니다. 이전 판은 드라이브 **버전 기록**에 남습니다.
- 🎨 **읽기 테마** — 종이 · 세피아 · 다크 3종 + 글자 크기(A− / A+) 조절.
- 🔐 **세션 유지** — 토큰을 만료 전까지 보관하고, 만료가 다가오면 조용히 연장을 시도합니다.
  연장 팝업이 차단되면 상단에 "🔄 세션 연장" 칩이 떠서 클릭 한 번으로 이어집니다.

> **프라이버시**: 이 페이지가 공개되어 있어도 **여러분의 파일이 공개되는 게 아닙니다.**
> 파일 접근 권한은 전적으로 구글 드라이브가 결정하며, 이 앱은 그 권한을 우회하지 않습니다.

## 설정 (한 번만)

구글 드라이브에 접근하려면 본인의 **Google Cloud 프로젝트**에서 아래를 만든 뒤,
`config.js` 에 값을 채워 넣습니다. (약 5~10분)

### 1. API 사용 설정
[Google Cloud Console](https://console.cloud.google.com/) 에서 프로젝트를 하나 선택(또는 생성)하고,
**API 및 서비스 → 라이브러리**에서 다음을 **사용 설정**합니다.
- **Google Drive API**
- **Google Picker API** (SCOPE_MODE "file" 의 파일 선택창용, 선택)

### 2. API 키 만들기
**API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**
- 만든 키를 눌러 **애플리케이션 제한 → HTTP 리퍼러(웹사이트)** 선택 후 아래를 추가:
  - `https://teo-kt.github.io/*`
  - `http://localhost:*` (로컬 테스트용)
- **API 제한**은 *Google Drive API* 와 *Google Picker API* 로 한정하는 것을 권장합니다.

> ⚠️ API 키는 이렇게 **리퍼러 제한**을 걸면 공개돼도 안전합니다. (그래서 `config.js` 를 커밋해도 됩니다.)

### 3. OAuth 클라이언트 ID 만들기
**사용자 인증 정보 만들기 → OAuth 클라이언트 ID → 애플리케이션 유형: 웹 애플리케이션**
- **승인된 자바스크립트 원본**에 다음을 추가:
  - `https://teo-kt.github.io`
  - `http://localhost:8000` (로컬 테스트용, 원하는 포트로)
- 리다이렉트 URI는 필요 없습니다(토큰 방식).

**OAuth 동의 화면**: 사용자 유형을 *외부*로 만들었다면, **테스트 사용자**에 본인 계정을 추가하세요.

### 4. `config.js` 채우기
```js
window.HTMLBOOK_DRIVE_CONFIG = {
  CLIENT_ID: "1234567890-xxxx.apps.googleusercontent.com", // OAuth 클라이언트 ID
  API_KEY:   "AIzaSy...",                                   // API 키(리퍼러 제한 필수)
  APP_ID:    "1234567890",                                  // GCP 프로젝트 번호(숫자)
  SCOPE_MODE: "full",                                       // 아래 참고
};
```

### SCOPE_MODE — 권한 범위 선택

| 값 | 권한 | 되는 것 |
|----|------|---------|
| `"full"` | 드라이브 읽기+쓰기 | 파일 탐색기 · 열람 · **편집·자동 저장** (개인용 권장) |
| `"readonly"` | 드라이브 전체 읽기 | 파일 탐색기 · 열람 (편집 불가) |
| `"file"` | 고른 파일만 | Picker 로 선택한 파일 열람만 (최소 권한) |

`"full"` / `"readonly"` 는 제한(restricted) 범위라 앱을 일반 공개하려면 구글 심사가 필요하지만,
OAuth 동의 화면이 **테스트** 상태이고 본인이 **테스트 사용자**면 심사 없이 쓸 수 있습니다.
- 로그인 시 "Google 에서 확인하지 않은 앱" 경고가 나오면 **고급 → (앱 이름)(안전하지 않음)으로 이동**.
  본인이 만든 앱이므로 안전합니다.
- 테스트 상태의 동의는 **7일마다 만료**될 수 있어, 일주일에 한 번쯤 동의 화면이 다시 뜹니다.

## 사용법

1. **구글 로그인** → 왼쪽 **파일 탐색기**에서 폴더를 열고 파일을 클릭합니다.
   - 🔍 검색창에서 이름으로 찾고, 폴더 결과의 📌 로 사이드바에 고정할 수 있습니다.
     ("컴퓨터(다른 컴퓨터)" 등 트리에 안 보이는 위치도 검색 → 고정으로 접근합니다.)
2. 문서 상단의 모드 버튼:
   - **보기** — 렌더된 문서.
   - **본문 편집** (HTML) — 화면에서 텍스트를 탭해 바로 수정. 편집 중에는 문서 스크립트가 잠시 꺼집니다.
   - **소스 / 편집** — 코드 편집기 + 실시간 미리보기.
3. 고치면 자동 저장됩니다. 상단 칩(● 수정됨 → 저장 중… → ✓ 저장됨)으로 상태를 확인하세요.
4. **공유 링크 붙여넣기** — '링크가 있는 모든 사용자'로 공유된 파일은 로그인 없이도 봅니다.

지원하는 링크 형태(자동 인식):
```
https://drive.google.com/file/d/<파일ID>/view
https://drive.google.com/open?id=<파일ID>
https://drive.google.com/uc?id=<파일ID>&export=download
<파일ID> 문자열 자체
```

### 폰에서 앱처럼 쓰기
- **iOS Safari**: 공유 → **홈 화면에 추가**.
- **Android Chrome**: 메뉴 → **홈 화면에 추가**.
- 열었던 문서는 URL 해시(`#f=파일ID`)로 복원되므로, 문서를 연 상태로 추가하면 그 문서 바로가기가 됩니다.

## 로컬에서 실행

```bash
python3 -m http.server 8000
```
브라우저에서 http://localhost:8000 접속.
> `file://` 로 직접 열면 구글 로그인/일부 fetch가 막힙니다. 반드시 `http://localhost` 로 여세요.
> (OAuth 원본에 등록한 포트와 같아야 합니다.)

## 동작 방식 / 기술

| 구성 | 내용 |
|------|------|
| 형태 | 순수 클라이언트 사이드 정적 사이트(서버 없음). `app.js`(코어) · `browser.js`(탐색기) · `editor.js`(편집·저장) |
| 로그인 | Google Identity Services 토큰 방식. localStorage 보관 + 만료 전 조용한 갱신 + 401 자동 재시도 + `login_hint` 로 재동의 마찰 최소화 |
| 파일 읽기 | Drive API v3 `files.get?alt=media` (토큰 또는 API 키). 바로가기(shortcut)는 대상 파일로 자동 이동 |
| 파일 저장 | `PATCH upload/drive/v3/files/<id>?uploadType=media` + 저장 전 `version` 비교로 충돌 감지 |
| 탐색기 | `files.list` (폴더 트리 lazy 로딩·5분 캐시, `name contains` 검색, 별표, viewedByMeTime 최근) |
| Markdown | [marked](https://github.com/markedjs/marked) + [DOMPurify](https://github.com/cure53/DOMPurify) 살균 |
| HTML 보기 | 샌드박스 `<iframe>` + Blob URL. 자체 스타일이 있으면 원본 그대로(기본 스크립트 차단, 토글 허용), 스타일이 없으면 리더 테마 주입. `#앵커`는 프레임 안에서 이동, 외부 링크는 새 탭 |
| 본문 편집 | 렌더 화면의 텍스트 블록(제목·문단·리스트·표 셀 등, 가장 안쪽 블록만)에 `contenteditable` 부여 → 수정분을 소스에 정밀 텍스트 패치(유일 매칭 치환, 실패 시 DOM 직렬화 폴백). 편집 중 문서 스크립트는 제거된 사본을 렌더하므로 런타임 생성 텍스트를 실수로 편집하는 문제가 없습니다 |
| 소스 편집 | CodeMirror 5 (벤더 번들) + 디바운스 미리보기 |

## 한계

- **구글 문서/시트/슬라이드**(`application/vnd.google-apps.*`)는 지원하지 않습니다. 업로드된 `.html` / `.md` / `.txt` 파일만 지원합니다.
- 외부 리소스(다른 곳에 있는 이미지 등)를 참조하는 HTML은 그 리소스 접근 권한에 따라 일부가 안 보일 수 있습니다. **자체 완결형(self-contained) HTML** 은 완벽하게 표시됩니다.
- 본문 편집은 텍스트 수정에 최적화되어 있습니다. 요소 추가/삭제·구조 변경은 소스 모드를 쓰세요.
- 액세스 토큰 수명(1시간)은 구글이 정한 것이라 늘릴 수 없습니다. 대신 만료 전 조용한 연장과
  401 자동 재시도로 체감상 로그아웃 없이 이어집니다.
- OAuth·Picker는 구글이 호스팅하는 스크립트를 불러오므로 완전 오프라인은 아닙니다(뷰어 자체는 정적).
